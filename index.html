What it does

  • Supports 6 query types: startup discovery, funding intelligence, competitor comparisons, sector reports, hiring trends, investor research.
  • Reviews and filters every retrieved entity with a keep/reject decision before the report is drafted, not after.
  • Outputs a professional Word document, delivered by email, with a Streamlit dashboard as the front end.

Problems I solved

  • Token-limit crashes: a 30+ source pipeline blew past LLM context limits. Fixed by batching 6 sources per LLM call — full pipeline now runs without crashes.
  • Noisy retrieval: built a dedicated Review Agent that filters 13–18 irrelevant items per query before report generation, so output quality doesn't degrade as source count grows.
  • Deployment: containerized with Docker, orchestrated Tavily + Groq LLM + SendGrid + python-docx into one pipeline behind a single dashboard.

What it does

  • Lets users query Arabic PDF documents in either Arabic or English and get accurate, sourced answers back.
  • Uses Arabic-Triplet-Matryoshka-V2 embeddings (768-dim) with top-3 semantic retrieval via ChromaDB.
  • Keeps conversation cost flat over long sessions via hybrid memory: last 2 full exchanges + an LLM-generated rolling summary.

Problems I solved

  • Corrupted extraction: non-standard Arabic font encoding broke direct PDF text extraction. Switched to Tesseract OCR — reliable extraction across all 81 pages and every tested document.
  • Cross-lingual retrieval failure: English queries weren't matching Arabic-embedded chunks. Fixed by translating queries to Arabic before embedding, aligning both into the same vector space.
  • 403 upload errors on deploy: Streamlit's XSRF protection was misreading reverse-proxy headers on Hugging Face Spaces. Diagnosed and resolved with custom CORS configuration.
